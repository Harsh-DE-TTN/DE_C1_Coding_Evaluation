## How seed data is produced

Generated by `src/data_generation/generate_sample_data.py` with `RANDOM_SEED=42`.

```bash
python3 src/data_generation/generate_sample_data.py
```

See [DATA_GENERATION_NOTES.md](../src/data_generation/DATA_GENERATION_NOTES.md) for full schema, distributions, and intentional defects.

## Regenerating seed data

1. Run the generator locally.
2. Upload refreshed CSVs to Databricks Volume/DBFS.
3. Re-run Bronze → Silver → Gold pipeline.
